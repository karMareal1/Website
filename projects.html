Class Pollution

Class Pollution is a project that explores the impact of pollution on different social classes in a city. This project uses data visualization and interactive elements to demonstrate how pollution affects various neighborhoods differently.

  • Technologies: Python, Data Visualization, Interactive Web Interface
  • Features: Real-time pollution data tracking, Neighborhood impact analysis, Interactive maps
  • Impact: Raises awareness about environmental justice issues and pollution distribution

Python Sandbox Escape

Python Sandbox Escape is a security-focused project that demonstrates how to escape Python's built-in security sandbox. This project explores Python's security mechanisms and potential vulnerabilities.

  • Technologies: Python, Security Research, System Exploitation
  • Features: Sandbox bypass techniques, System access demonstration, Security testing framework
  • Impact: Helps developers understand Python security limitations and improve code security
